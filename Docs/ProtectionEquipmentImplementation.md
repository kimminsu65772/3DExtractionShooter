# INV-02(장비) 보호 장비 연결 — 2026-10-06

## 책임

- ProtectionDefinition: 방어 등급, 최대 내구도, 장비 손상 배율을 정의한다.
- ArmorInstance: 한 물건의 현재 내구도와 보호 효과 계수를 보관한다. 방어구와 헬멧 모두 사용한다.
- ArmorInventoryItem: 인스턴스를 인벤토리 아이템으로 감싼다. 이동할 때 인스턴스를 다시 만들지 않는다.
- ProtectionEquipment: 몸통 방어구와 헬멧을 서로 다른 칸에 보관한다.
- InventoryEquipmentTransferService: 가방·상자와 장비 사이 소유권을 이동하거나 교환한다.
- PlayerEquipment: 행동 상태를 확인하고 이동 서비스를 호출하며 IProtectionProvider로 장비를 제공한다.
- HealthComponent: 피격 부위의 장비를 조회하고 피해와 내구도 손상을 계산한다.

## 적용 규칙

- 내구도 50% 이상은 정상 보호, 0% 초과·50% 미만은 피해 감소 효과 절반, 0%는 보호 효과 없음으로 처리한다. 소진된 물건 자체는 남긴다.
- 방어구 등급이 관통 등급보다 높은 경우 기존 피해 배율 2 / (등급 차이 + 2)를 사용한다. 같으면 피해 10%, 관통 등급이 하나 높으면 5%, 둘 이상 높으면 2.5%를 감소한다. 방어구가 없으면 감소하지 않는다.
- 피해를 피격 전 내구도로 계산하고 체력과 내구도를 변경한 뒤 알림을 보낸다. 무적·사망·유효하지 않은 피해는 내구도를 차감하지 않는다.
- 장비 제공자가 있는 플레이어의 빈 장비 칸은 방어 등급 0으로 처리한다. 제공자가 없는 적은 기존 CharacterStats의 방어 등급을 사용한다.
- UI 장비 칸은 무기 1, 무기 2, 방어구, 헬멧 순서다. 무기 퀵슬롯은 기존 두 칸이다. 빈 칸 자동 장착, 드래그 교환과 해제, 보호 장비 더블클릭 해제를 연결했다.

## 초기값과 미완료 범위

- 게임 CSV는 이번 작업에서 수정하지 않았다. 선택 열 maxDurability / durabilityDamageMultiplier가 없으면 기본 100 / 1을 사용한다. 원본 에셋 CSV의 아이템별 최대 내구도 반영은 아직 하지 않았다.
- 초기 손상 공식은 방어 전 피해 × durabilityWearCoefficient × (1 + 관통 등급 × penetrationWearPerLevel) × 장비 손상 배율이다. HealthComponent의 인스펙터 초기값 0.1 / 0.25는 조정 가능한 제안값이며 확정된 밸런스가 아니다.
- 외형 부착, 수리, 방어구의 추가 가방 칸 적용과 해제 시 초과 아이템 드롭은 이번 작업에 포함하지 않았다.
- 순수 모델 검사와 실제 HealthComponent 메서드 검사를 실행했다. Unity 씬에서 상자 획득·UI 장착·피격·회피·해제의 플레이 검증은 별도로 진행한다.
