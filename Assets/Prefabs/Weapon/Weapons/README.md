# Weapon asset selections

- AK-47: base WPN_AK47; excludes AK47_Fire variant.
- Glock: base WPN_Glock with Glock_01 maps; excludes alternate Glock_02 texture.
- MF: matched to the available WPN_M4 model family; includes its muzzle, scope, and stock meshes. Excludes M4_Poison variant.
- MP-155: base WPN_MP155; excludes MP155Ultima.

Source folders: Mesh, Texture2D, Sprite. Files were copied into this selection; originals remain in place.
